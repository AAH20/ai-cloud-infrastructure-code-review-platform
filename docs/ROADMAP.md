# Roadmap

## v0.1 — product trust kernel

Authenticated webhooks, tenant isolation, idempotency, supersession, deterministic decisions, signed evidence, CLI, Action, Azure foundation and tests.

## v0.2 — native evidence execution

Terraform/OpenTofu plans, Bicep what-if, Kubernetes dry run, Checkov, Infracost and ChangeBench adapters with tool-version provenance.

## v0.3 — hosted design-partner release

GitHub App registration, GitHub Checks API, Azure Container Apps API/workers, Service Bus, PostgreSQL, Key Vault, managed identity and OpenTelemetry.

## v1.0 — enterprise operation

Tenant-scale load tests, SLOs, disaster recovery, private deployment, signed supply chain, evidence custody, policy packs, billing meters and independently reproduced case studies.
